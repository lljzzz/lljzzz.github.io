Privacy Policy

Last updated 7 October 2026

The short version: the Volt app collects nothing and sends nothing. It has no network code, so it cannot. This website uses no cookies, no analytics and no third-party fonts or scripts. The only data involved is what GitHub, which hosts this site and the downloads, logs on their own servers.

Who is responsible

Volt is an open source project made by lljzzz. The best way to reach us is to open an issue on GitHub. Issues are public, so please don't include anything private. If you need to tell us something privately, open an issue saying so and we'll find a way to talk.

The Volt app

Volt never connects to the internet. It has no accounts, no telemetry, no crash reporting and no update checks. We do not receive any information about you, your computer or how you use the app.

Everything Volt stores stays on your computer:

  • Settings, macros, snippets, notes and clipboard pins, saved as plain JSON files in %APPDATA%\Volt, or in the VoltData folder next to Volt.exe when you use portable mode.
  • Clipboard history, kept in memory while Volt runs and saved to the same folder only if you turn on "Remember history across restarts". Volt skips copies that password managers mark as private.
  • Screenshots, saved as PNG files in the folder you choose (by default Pictures\Volt).

You control this data completely. You can read, back up or delete these files at any time. Deleting the folder removes everything Volt has stored. Export files you create are saved wherever you choose and are never sent anywhere.

This website

This website does not use cookies, analytics, advertising or tracking of any kind. It loads no fonts, scripts or embeds from third parties.

The site is hosted on GitHub Pages, a service of GitHub, Inc. in the United States. According to GitHub, when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes. We don't have access to those logs. GitHub's handling of them is described in the GitHub General Privacy Statement.

Volt is downloaded from GitHub Releases, so the same GitHub privacy statement applies to downloads.

Contacting us

If you open an issue or comment on GitHub, your message and GitHub username are public on GitHub and are handled under GitHub's terms. We only use them to answer you and improve Volt.

Your rights

Depending on where you live, you may have the right to access, correct or delete personal data about you, to object to its use, and to complain to a data protection authority. Because the app collects nothing and this site has no tracking, we don't hold personal data about visitors. For server logs, contact the website host or GitHub as described in their privacy policies. For anything else, get in touch on GitHub.

Changes to this policy

If this policy changes, we will update this page and the date at the top. If a future version of Volt ever needed a network connection, we would say so clearly here and in the release notes before shipping it.
