Automate

Autoclicker

Clicks at any rate you set, with the controls a basic clicker is missing.

  • Clicks per second, minute or hour, or an exact interval.
  • Humanized timing that varies each click while the average stays on target.
  • Sequences: mark points with F7, finish with F8, and Volt clicks or drags through them in order.
  • Failsafes: only click in a chosen window, or stop when focus changes.

Toggle with Ctrl+Y, or hold to click.

Macros

Record keyboard and mouse input, edit it step by step, replay it with a hotkey.

  • Change delays, keys and positions, or reorder steps after recording.
  • Repeat, loop, or play at 0.1x to 10x speed.
  • Keys are sent as hardware scan codes, so they work in many games.
  • Stopping a macro always releases every key it was holding.

Snippets

Type a short trigger anywhere and Volt replaces it with the full text.

You type
;addr
You get
your full address
  • Placeholders for {date}, {time}, {clipboard} and where the cursor lands.
  • Multi-line snippets are pasted, not typed, so chat apps don't send half a message.
  • Works with international keyboards, including AltGr characters.

Productivity

Clipboard history

Everything you copy, searchable, with pins for the things you paste often.

  • Pins survive restarts. The full history can too, if you want.
  • Skips copies that password managers mark as private.
  • Copy any entry as UPPER, camelCase, Base64, pretty JSON and 21 more formats.

Ctrl+Shift+V pastes as plain text.

Notes

Plain-text notes that save as you type. The first line is the title. Type note: buy milk in the palette to add one.

Text tools

Change case, sort lines, encode Base64 or URLs, format JSON and hash text. Also makes UUIDs, timestamps and strong passwords.

Timers

Presets, durations like 1h30, or an alarm at a set time. You get a notification and a beep, even with the window closed. Stopwatch included.

Screen

Screen capture

Freeze the screen, drag a region, and the shot is on your clipboard and saved as a PNG.

  • Full screen and 3-second delay captures too.
  • Pin a capture on top of everything to use as a reference.
  • Correct on multiple monitors and scaled displays.

Ctrl+Shift+X from anywhere.

Color picker

Pick any color on screen with a pixel magnifier and copy it as HEX, RGB or HSL.

Ctrl+Alt+C

Nudge

Move the cursor or the active window by exact pixel steps from the keyboard, jump to saved spots, and snap windows to halves or quarters.

Ctrl+Alt+Arrows cursor · Win+Alt+Arrows window

Your stuff stays on your PC

Volt sees what you copy and type: your clipboard, your notes, snippets with your address in them. None of it ever leaves your computer.

Files you can open

Everything is saved as plain JSON in %APPDATA%\Volt. Read it, back it up or delete it.

Nothing to send it with

Volt has no network code. No telemetry, no update checks.

No account

Nothing to sign up for, nothing to log in to.

Take it with you

Put an empty file named portable next to Volt.exe and everything lives in one folder. Great for a USB stick.

One-file backup

Export and import all your settings, macros and snippets as a single file.

Check for yourself

The code is open source under the MIT license, so you don't have to take our word for it. Read the source on GitHub.

Download Volt

One portable exe. No installer.

  1. Download Volt.exe.

  2. Run it. No admin rights needed.

  3. If SmartScreen warns you, click More info, then Run anyway. The exe isn't code-signed yet.

  4. Done. Volt adds a tray icon and keeps running when you close the window.

Some antivirus tools flag apps that simulate input, because that's what autoclickers do. Volt has no network code at all, and you can scan the exe on VirusTotal yourself before running it.

Questions

Is it safe? Why did my antivirus flag it?

Volt simulates keyboard and mouse input, which some antivirus tools flag in unsigned apps. It has no network access, and the code is open for anyone to check. You can also scan the exe on VirusTotal.

Does it collect any data?

No. Nothing leaves your PC.

Can I get banned in a game?

It can happen. Many online games forbid automation, so check the rules before you use it. Volt is a general tool and isn't responsible for bans.

Is it really free?

Yes. It's free and open source under the MIT license, with no account needed.

Does it work on Mac or Linux?

No, Windows 10 and 11 only.

Can I run it from a USB stick?

Yes. Put an empty file named portable next to Volt.exe.

How do I stop everything at once?

Press Ctrl+Shift+M, or pick Stop everything in the tray menu.

Does the window have to stay open?

No. Close it and Volt keeps working from the tray.

I found a bug. Where do I report it?

Open an issue on GitHub. Include your Windows version and what you were doing when it happened.
