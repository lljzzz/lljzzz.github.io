Download Volt

One executable, with no installer and no account to create.

  1. Download Volt.exe. Save it somewhere you want to keep the app.

  2. Open it. Choose a tool or press Ctrl+Alt+Space to search.

  3. Close the window when you're done. Volt keeps running in the system tray. Right-click its tray icon to quit.

Updating from an older version

Quit Volt from its tray menu, replace the old Volt.exe with the new download, then reopen it. Keep your data folder. In portable mode, also keep the portable marker and VoltData folder beside the EXE.

Using portable mode

Put an empty file named portable (with no extension) beside Volt.exe before opening it. Volt then uses a VoltData folder there. Without the marker, the EXE stores data in %APPDATA%\Volt.

Why does Windows show a warning?

Volt 0.8 is not digitally signed, so Windows may show an unknown-publisher or SmartScreen warning. If you trust this download, Windows may offer More info → Run anyway. You can review the source and compare the download's SHA-256 checksum before deciding to run it.

Unsigned apps that simulate keyboard and mouse input can also trigger antivirus detections. If a security tool flags this file, check the detection rather than assuming it is harmless.

Q&A

Have another question? Ask on GitHub.

Does Volt send my data anywhere?

No. Clipboard history, notes, macros and settings stay on your PC. Volt has no analytics, cloud sync or automatic crash reports. See what is stored and where.

How can I check the download?

Download from the project's GitHub releases, compare the file's SHA-256 checksum, and review the source if you want to inspect the code. Volt 0.8 is unsigned, so Windows may show a warning. About that warning.

Why might antivirus flag Volt?

The autoclicker, macros and snippets work by simulating keyboard and mouse input, and some security tools flag unsigned apps that do that. Volt has no network code, and the source is on GitHub if you want to check what it does.

Is Volt really free?

Yes. Volt is free and open source under the MIT license. No account or subscription is required.

Does it work in browsers and other apps?

Yes. Global shortcuts, text expansion and clipboard tools work across Windows apps. Some games or apps running as administrator may handle simulated input differently.

Can I change the hotkeys?

Yes, all of them, in Settings or on each tool's page. Volt warns you when two hotkeys clash, and you can switch any tool's hotkeys off from the Dashboard.

Can I use macros in a game?

Check the game's rules first. Some games prohibit automation and may penalise its use. Volt doesn't bypass those rules or anti-cheat systems.

Does it work on Mac or Linux?

No. Volt currently supports 64-bit Windows 10 and 11.

Does closing the window stop Volt?

By default, closing the window leaves Volt running in the system tray, so shortcuts and background tools still work. To exit, right-click the tray icon and choose Quit.

How do I report a bug?

Open an issue with your Volt version, Windows version, what you were doing and any error message. Don't include private clipboard content or personal data.
